## About Me

I'm a Computer Science undergrad at **NIT Hamirpur**, focused on **smart contract development** — building decentralized systems and writing secure Solidity contracts. I like the problem of removing trusted middlemen from processes that don't need them: verified access control, on-chain tracking, and contracts that hold up under testing.
